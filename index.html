DoubleWindows

Windows tuşuna çift basınca Ayarlar’ı açan, sol Shift’e çift basınca Caps Lock’u değiştiren masaüstü aracı.

Windows 64-bit

Çoğu modern bilgisayar için.

x64 Setup.exe indir ↗

Windows 32-bit

32 bit Windows kullanan bilgisayarlar için.

x86 Setup.exe indir ↗

İndirme sayfasında Artifacts bölümünden DoubleWindows-Setup-x64 veya DoubleWindows-Setup-x86 ZIP dosyasını seç. ZIP’i açıp içindeki Setup.exe dosyasını çalıştır. Bu derleme bağlantıları GitHub Actions arşivine gider ve 30 gün sonra sona erer.

YouTube bağlantısı

Gerçek YouTube araması ve trend videolar için Google YouTube Data API v3 anahtarı gerekir. Anahtar yalnızca bu tarayıcıda saklanır; GitHub deposuna gönderilmez. Google Cloud Console’da anahtarı HTTP referrer ile kendi sitene kısıtla.

API anahtarı olmadan YouTube videolarını arama ve trend akışını otomatik çekemeyiz. Video oynatma, YouTube’un resmi gömülü oynatıcısını kullanır.
