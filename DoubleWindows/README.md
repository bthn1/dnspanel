# DoubleWindows

Windows kısayol uygulaması.

- Windows tuşuna hızlıca iki kez basınca Windows Ayarları'nı açar.
- Sol Shift tuşuna hızlıca iki kez basınca Caps Lock durumunu değiştirir.
- Sistem tepsisinde çalışır; tepsi menüsünden Ayarlar açılabilir veya uygulamadan çıkılabilir.

## Kurulum dosyaları

GitHub Actions, x64 ve x86 için ayrı Windows kurulum dosyaları üretir. Depoda **Actions → Build DoubleWindows Setup** iş akışını çalıştırıp ilgili çalışmanın Artifacts bölümünden `DoubleWindows-Setup-x64` veya `DoubleWindows-Setup-x86` dosyasını indirebilirsin.

Kurulum dosyası Python gerektirmez.
